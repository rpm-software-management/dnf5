If terminal is available, list of the packages is colored, packages available for reinstall are
(by default) colored with bold green and packages available for upgrade with bold blue. This
behavior can be adjusted via the :ref:`color_list_available_upgrade
<color_list_available_upgrade_options-label>` and :ref:`color_list_available_reinstall
<color_list_available_reinstall_options-label>` configuration options.
